Sprint 2 (N2) — CRUD Local
Apresentação documentada: 20/10/2026.
Evolução registrada no relatório
- Aplicação React/Vite com páginas Home, Vagas, Profissionais e Cadastro.
- Componentes em arquivos separados, incluindo Navbar.
- CRUD local de vagas com criação, listagem, edição e exclusão.
- Uso de localStorage para persistir dados no navegador.
- Cadastro de usuários com nome, e-mail, senha e tipo (profissional/empresa).
- Melhoria da interface e da navegação.
Dificuldades e aprendizados
O relatório descreve conflitos de Git causados por edições simultâneas e a necessidade de melhorar a divisão de arquivos e uso de branches.
Observação técnica
O relatório registra que o cadastro armazenava senhas em texto simples no localStorage, algo inadequado para produção. Esta é uma limitação histórica da N2, não uma recomendação.
